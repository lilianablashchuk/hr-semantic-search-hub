# Оцінка Soft Skills та мінімізація когнітивних упереджень

## 1. Ключові Soft Skills для інженерних команд
Для IT-спеціалістів критичними є чотири групи м'яких навичок: структурована комунікація (здатність пояснити складну технічну проблему нетехнічному замовнику), автономність та проактивність, вміння працювати зі зворотним зв'язком (Coachability) та командна співпраця у розподіленому середовищі.

## 2. Типові когнітивні упередження інтерв'юерів
Під час співбесіди інтерв'юери часто потрапляють у пастку психологічних ефектів:
- **Ефект ореолу (Halo Effect):** одна яскрава перевага (наприклад, престижний університет або попередня компанія) змушує завищувати оцінки за всіма іншими критеріями.
- **Упередження схожості (Affinity Bias):** схильність вище оцінювати кандидатів зі схожими хобі, стилем спілкування чи бекграундом.
- **Ефект першого враження (First Impression Bias):** прийняття рішення у перші 3 хвилини розмови та подальший пошук лише підтверджень цієї думки.

## 3. Інструменти об'єктивізації оцінки
Для зниження суб'єктивності кожен інтерв'юер заповнює власну оціночну картку до обговорення кандидата на калібрувальній зустрічі (Debrief). Використовуються стандартизовані запитання та поведінкові індикатори для кожного балу шкали.
