# Профіль вакансії: Junior / Strong Junior QA Engineer (Manual + Automation)

## 1. Завдання на посаді
Спеціаліст відповідатиме за забезпечення якості вебзастосунків та API-сервісів. Основні обов'язки включають аналіз вимог, створення та актуалізацію тестової документації (чек-листи, тест-кейси в TestRail), проведення функціонального, регресійного та інтеграційного тестування, а також поступову автоматизацію критичних сценаріїв.

## 2. Вимоги до кандидата
- Чітке розуміння теорії тестування ПЗ, життєвого циклу розробки (SDLC) та життєвого циклу дефекту (Bug Life Cycle).
- Практичний досвід тестування REST API за допомогою Postman або Swagger, розуміння HTTP-методів та статус-кодів.
- Вміння працювати з Chrome DevTools та писати базові SQL-запити (JOIN, GROUP BY).
- Базові знання Python або JavaScript та досвід написання простих UI/API автотестів (Playwright, Pytest або Selenium).
- Уважність до деталей, системне мислення та вміння чітко описувати кроки відтворення дефектів у Jira.

## 3. Умови та менторство
Для Junior-спеціалістів передбачена програма адаптації з ментором на перші 3 місяці, регулярні code review автотестів та доступ до корпоративної бази знань.
