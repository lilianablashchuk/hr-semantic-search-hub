# Профіль вакансії: Middle Python Backend Developer

## 1. Опис ролі та проєктного контексту
Ми шукаємо Middle Python Backend Developer для розвитку хмарної платформи аналітики міської безпеки та маршрутизації. Команда працює за методологією Scrum (2-тижневі спринти) та будує мікросервісну архітектуру з високими вимогами до швидкодії геопросторових запитів.

## 2. Обов'язкові технічні вимоги (Must-have)
- Впевнене володіння Python 3.11+ та асинхронним програмуванням (`asyncio`).
- Комерційний досвід розробки REST API на FastAPI або Django REST Framework від 2.5 років.
- Глибокі знання реляційних баз даних (PostgreSQL, PostGIS), оптимізація SQL-запитів та індексів.
- Досвід контейнеризації застосунків за допомогою Docker та Docker Compose, розуміння базових принципів CI/CD.
- Рівень англійської мови — Intermediate+ (B1+/B2) для читання документації та участі в демо.

## 3. Бажані навички (Nice-to-have) та етапи відбору
Буде перевагою досвід роботи з Redis, чергами повідомлень RabbitMQ або Kafka, а також бібліотеками аналізу даних (pandas, NumPy). Процес відбору складається з 3 кроків: HR Pre-screen (20 хв), технічне інтерв'ю з Python Tech Lead (75 хв) та фінальна розмова з Product Owner (30 хв).
