# Профіль вакансії: Middle Data Analyst / BI Specialist

## 1. Бізнес-задачі позиції
Data Analyst допомагає продуктовим та HR-командам приймати рішення на основі даних (Data-Driven Decisions). Ви будуватимете вітрини даних, досліджуватимете когортну утримуваність користувачів, проводитимете A/B тестування продуктових фіч та автоматизуватимете управлінську звітність.

## 2. Необхідні навички та інструменти
- Експертне володіння SQL (віконні функції, CTE, оптимізація запитів у BigQuery або PostgreSQL).
- Впевнене використання Python (pandas, NumPy, SciPy, Matplotlib/Seaborn) для статистичного аналізу та перевірки гіпотез.
- Досвід розробки інтерактивних дашбордів у Power BI, Tableau або Looker Studio.
- Розуміння математичної статистики (p-value, довірчі інтервали, статистична потужність тесту).

## 3. Етапи інтерв'ю
Кандидати проходять HR-скринінг, практичне кейс-інтерв'ю зі SQL та продуктовими метриками (60 хв) і фінальну зустріч із Head of Analytics.
