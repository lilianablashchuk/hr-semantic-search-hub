# Профіль вакансії: Junior DevOps / Application Support Engineer

## 1. Опис ролі та зони відповідальності
Роль поєднує підтримку стабільності продакшн-середовищ (Application Operations) та автоматизацію процесів розгортання. Інженер моніторить стан сервісів, аналізує логи інцидентів 2-ї лінії підтримки, підтримує CI/CD пайплайни та допомагає розробникам із налаштуванням тестових стендів.

## 2. Технічні компетенції
- Впевнене адміністрування Linux (Ubuntu/Debian), знання Bash-скриптингу та мережевих протоколів (TCP/IP, DNS, HTTP/HTTPS, SSH).
- Практичний досвід роботи з Docker, написання оптимізованих Dockerfile та конфігурацій Docker Compose.
- Розуміння систем контролю версій Git та побудови CI/CD у GitHub Actions або GitLab CI.
- Базовий досвід роботи з хмарними провайдерами (AWS або Google Cloud Platform) та системами моніторингу (Prometheus, Grafana, ELK Stack).

## 3. Графік та особливості роботи
Робота у гібридному форматі або віддалено. Передбачено чергування On-call за окрему компенсацію після завершення випробувального терміну.
